# 容器工作台设计说明

> 日期：2026-10-24
> 主线：PRODUCT-WORKBENCH-001
> 状态：已完成

## 范围与验收

在 Electron 中增加只读的本机 Docker 容器列表。Web 不注册容器工作台，也不包含 Docker IPC。当前切片不启动、停止、重启、删除容器，也不读取日志、环境变量、标签或挂载。

- 仅在主进程调用 PATH 中的 `docker` 程序；命令使用参数数组，不经过 Shell。
- 列出最近创建的最多 100 个容器，界面只显示容器 ID、名称、镜像、状态、状态说明和端口映射。
- 单次请求最多运行 10 秒，标准输出最多 512 KiB。超过任一限制时返回固定错误，不把 CLI 诊断或环境变量传给渲染器。
- 每个窗口最多一个活动请求。用户可取消请求；窗口关闭或离开工具时，主进程终止对应子进程。
- 页面提供手动刷新、名称/镜像筛选、状态、错误和取消反馈。没有可用 Docker CLI 时显示固定的不可用状态。
- 对于无效容器记录、超长字段或超过记录上限的响应，主进程拒绝整份响应，不返回部分或未校验的数据。
