## 范围与验收

Electron 提供只读的本机 Docker 容器列表。Web 不注册容器工作台，也不包含 Docker IPC。当前切片不启动、停止、重启、删除容器，也不读取日志、环境变量、标签或挂载。

- 仅在主进程调用 PATH 中的 `docker` 程序；命令使用参数数组，不经过 Shell。
- 列出最近创建的最多 100 个容器，界面只显示容器 ID、名称、镜像、状态、状态说明和端口映射。
- 单次请求最多运行 10 秒，标准输出最多 512 KiB。超过任一限制时返回固定错误，不把 CLI 诊断或环境变量传给渲染器。
- 每个窗口最多一个活动请求。用户可取消请求；窗口关闭或离开工具时，主进程终止对应子进程。
- 页面提供手动刷新、名称/镜像筛选、状态、错误和取消反馈。没有可用 Docker CLI 时显示固定的不可用状态。
- 对于无效容器记录、超长字段或超过记录上限的响应，主进程拒绝整份响应，不返回部分或未校验的数据。

## 验证与回滚

`pnpm test:e2e:container-workbench` 使用本机 Docker，检查容器名称、镜像、状态、端口和清理。协议与服务单测覆盖字段、上限、取消、超时和错误净化。Web 平台隔离流程检查入口隐藏和 `/container-workbench` 返回 404。

2026-10-24 的历史 Docker 集成使用 RustFS 1.0.1；隐藏 Electron 自动化和 390×844 布局检查通过，测试后确认容器已清理。该证据不代表当前版本、真实窗口或其他平台通过验收。当前缺口统一见主线计划，历史详情通过 Git 查询。

回滚只撤销对应页面、桥接、服务和测试，保留 API、Git、对象存储工作台和用户容器。该工具不执行任何容器写操作。
