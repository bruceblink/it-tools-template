# 历史开发记录

本目录保存已经完成的早期质量、安全、PWA 和依赖维护批次。它们用于追溯实现范围和验收证据，不作为当前开发入口。

当前唯一的主线开发计划是 [01-development-plan.md](../01-development-plan.md)。性能、平台和插件的现行设计与验证记录见 [07-performance-extensibility-design.md](../07-performance-extensibility-design.md)。接口和平台设计说明保留在 `docs/` 根目录。

归档文件保持原文件名，避免历史提交和证据引用失效。后续如果需要修改已完成范围，应在主线计划中建立新的任务，并链接到本目录的历史记录。
