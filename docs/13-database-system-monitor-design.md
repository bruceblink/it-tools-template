# 数据库管理工具与系统监视器设计说明

> 状态：已交付功能的技术说明
> 更新日期：2026-10-31
> 唯一执行计划：[主线开发计划](01-development-plan.md)

本文维护现有功能、服务边界和验证方法，不维护独立阶段或工期。跨平台、真实窗口与性能缺口统一列入主线计划。历史 S0–S8 阶段和逐次实施记录通过 Git 查询。

## 1. 术语与适用范围

| 名称 | English / 标识 | 职责与边界 |
| --- | --- | --- |
| 数据库适配器 | Database Adapter | 处理 PostgreSQL、MySQL 或 SQLite 的连接、结构、参数绑定、分页和取消，不负责界面 |
| 数据库会话 | Database Session | 持有连接与活动请求，不把驱动对象和密码返回界面 |
| 指标采集器 | Metrics Collector | 读取本机指标并计算差值，不控制进程或提升权限 |
| 指标快照 | Metrics Snapshot | 包含时间、来源、单位和状态；缺失值不伪装为零 |
| 桌面服务进程 | Desktop Service Process | 执行受审查的驱动与采集代码，不是第三方插件沙箱 |

数据库管理器和系统监视器仅在 Electron 注册。Web/PWA/Docker Web 不显示卡片、导航或搜索项，直接访问对应路由返回 Not Found。数据库驱动、本机采集代码和桌面 IPC 不进入 Web 产物。

| 模块 | 当前功能 | 范围限制 |
| --- | --- | --- |
| 数据库管理器 | 三引擎连接、结构浏览、分页、筛选排序、受限 SQL、当前页导出、单元格编辑、批量新增与删除草稿 | 不提供 DDL、迁移、备份恢复、SSH 隧道或远程操作系统监控 |
| 系统监视器 | 本机 CPU、内存、应用进程、磁盘、网络、进程列表、曲线、暂停恢复与断档 | 不提供远程采集、告警、长期历史或进程控制 |

普通数据库连接不提供远程主机全部指标。本机系统指标与数据库数据分别标明来源。两模块使用宿主私有桥接，不向外部插件开放数据库、凭据或进程列表。

## 2. 页面与服务结构

数据库页面包含连接和对象树、数据/结构视图、查询、结果及编辑草稿。系统监视页面包含本机概览、趋势、进程搜索和排序。页面沿用现有导航、主题、本地化和宽工作区；窄窗口通过工作区滚动处理表格宽度。

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 数据库界面 | `src/tools/database-manager/` | 连接状态、对象树、数据、SQL 和草稿；敏感内容留在页面内存 |
| 系统监视界面 | `src/tools/system-monitor/` | 快照、曲线、进程列表和显示偏好 |
| 桌面调用封装 | `src/platform-adapter/database.ts`、`src/platform-adapter/system-monitor.ts` | 类型化请求、取消和稳定错误 |
| 主进程与服务 | `electron/database/`、`electron/system-monitor/` | 来源检查、会话、驱动、采集、调度和清理 |
| 共享类型 | `src/shared/desktop-services/` | 请求、响应、错误和限额，不导入 Node 或驱动 |

调用方向为 Vue 页面 → 平台适配层 → 固定 preload 方法 → 主进程检查 → 对应服务。数据库与采集服务独立运行。SQLite 同步调用在 `utilityProcess` 中执行，避免阻塞 Electron 主进程；PostgreSQL 使用 `pg`，MySQL 使用 `mysql2`。

## 3. 凭据、会话与错误

- 只有受信任应用主框架可以调用桥接。入口检查发送者、来源、参数、会话和请求归属；插件、iframe、其他窗口及失效 ID 不能复用会话。
- 密码只用于当前内存会话。当前连接资料存储只保存不含密码的 PostgreSQL 元数据，不提供“记住密码”。旧设计中的 `safeStorage` 持久保存方案不作为已交付功能或新的排期。
- 密码提交后清空输入。连接串、密码、证书、SQL 和结果不写入 URL、分析事件或普通偏好；查询历史只留在当前连接内存中，最多 20 条。
- TLS 默认验证证书和主机名，失败不自动关闭验证。测试容器的不加密连接必须显式选择，不能扩大为生产默认值。
- 请求使用会话 ID、请求 ID 和页面代次。切换、取消和离开后忽略旧结果，释放连接、监听器和服务进程；普通显示偏好可以保留。
- 服务进程只接收允许的环境和输出配置。密码不进入命令行、环境变量或临时文件；错误使用稳定代码，不转发驱动原始敏感文本。

## 4. 查询、分页与编辑

表浏览使用元数据生成 SQL，按各引擎引用标识符并绑定参数。有稳定主键时优先使用键集分页；无主键或不支持的主键类型使用偏移分页，并说明并发变更可能导致重复或遗漏。

SQL 输入只接受受限单条 `SELECT`、`INSERT`、`UPDATE` 或 `DELETE`；拒绝 DDL、多语句、事务控制、参数占位符及受禁止的函数。连接默认只读，写入需先启用读写并通过原生确认。写 SQL 在事务中限制最多变更 1,000 行，超限回滚。

[结果处理](../electron/database/query-results.ts)在外层查询中限制字段，再交给驱动返回；不能只截断界面后声称服务内存有上限。数据库端的表达式计算和驱动分配仍需结合超时与压力测试验证。

| 范围 | 当前限制或行为 | 来源 |
| --- | --- | --- |
| SQL 输入 | 最多 16,384 个字符，受限单条语句 | [SQL 校验](../src/shared/desktop-services/sql-query.ts) |
| 返回页面 | 最多 25 行、16 列；每格展示最多 256 个字符 | [结果处理](../electron/database/query-results.ts) |
| 偏移 | 最多 1,000,000 行 | 同上 |
| 查询历史 | 当前连接内最多 20 条，不写磁盘 | 数据库页面状态 |
| PostgreSQL 连接资料 | 最多 20 条，不含密码；文件最多 64 KiB | [资料存储](../electron/database/postgres-connection-profile-store.ts) |
| 批量编辑 | 最多 100 行结构化新增或删除草稿，先预览再提交 | 数据库编辑流程 |

单元格编辑要求普通表、完整主键、未截断的可编辑值和原值冲突检查。查询结果只在可确认单表直列且包含完整主键时开放编辑；视图、无主键、二进制、截断值、联表、聚合和计算列保持只读。筛选与排序最多各 3 项，导出仅针对当前页。

PostgreSQL 支持请求级查询取消；MySQL 与 SQLite 同步查询沿用超时边界，不显示不支持的取消按钮。取消验收需要确认服务端查询结束。写入提交结果无法确认时显示结果未知并要求重新读取，不自动重试。

## 5. 系统采样与资源

主进程统一读取 `app.getAppMetrics()`，不由每个页面重复轮询。CPU 和基础内存使用本机 API；扩展信息使用受审查的采集实现。采集器不接受用户输入的 Shell 命令。高成本读取在服务进程执行，采样不叠加。

[共享限制](../src/shared/desktop-services/system-monitor.ts)规定默认采样 2 秒，可选范围 1–60 秒；扩展磁盘、网络和进程采样间隔 5 秒。历史最多 3,600 点，文件系统与网络接口各最多 64 项，进程最多 2,000 条。

差值使用单调时间。倒退、计数器重置或间隔超过 120 秒时重建基线并标明断档。暂停恢复不把断档两端画成连续曲线。无订阅者时停止采样，页面离开和窗口关闭时清理订阅与服务。

字段分别说明来源、单位与有效状态。全机 CPU、本应用进程 CPU、容量与速率不能混用；不支持、无权限、采样中和失败分开显示。进程列表不读取命令行、环境变量或打开文件。

资源验收固定机器、构建、刷新周期和输入。连续采样 30 分钟并切换路由 20 次，记录进程、连接、订阅、监听器、缓存点、CPU 和内存。历史 [Windows 资源报告](performance-system-monitor-resource-2026-10-24.json)不证明当前版本或其他平台通过；64 MiB 附加内存目标尚需按一致口径复核，待办见主线计划。

WASM 仅在剖析确认计算热点后评估。候选实现需在同环境下使 p95 CPU 时间至少改善 20%，且响应、取消、错误和体积不退化。WASM 不替代数据库 I/O、主机 API、进程隔离或权限检查；没有热点时保持现有实现。

## 6. 验证与回滚

按主线计划执行 `pnpm check`、Web 入口隔离、Electron 定向流程和真实窗口验收。数据库使用本地 Docker PostgreSQL 17+、MySQL 8.4+，SQLite 使用临时文件。记录镜像、实际版本、端口、启动与清理；不使用用户真实数据库。

数据覆盖 Unicode、复合主键、无主键、NULL、JSON、时间、精确数值、大字段、视图与并发修改。错误覆盖证书、权限、锁等待、超时、取消、提交中断和服务退出。真实窗口覆盖深浅主题、100%/150% 缩放、窄窗口、键盘、中英文与关闭流程。

回滚以关闭对应入口或撤销该功能提交为边界。保留用户数据库、连接资料和凭据；已经提交的数据库写入不能通过代码回退撤销。采集或编辑失败时，可以停用对应能力，不扩大外部插件权限。
